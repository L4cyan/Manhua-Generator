Who is in it

Read out of the prose. Appearance is the identity lock: it is copied verbatim into every prompt this character appears in, so a vague one is why a character turns up in a suit in one panel and a robe in the next. Fix it here, once, before hundreds of panels inherit it.

Storyboard

Every panel is reviewed as text before a single pixel is rendered. Fixing a wrong shot here costs nothing; fixing it after costs GPU minutes.

Art style

Panels already rendered keep their look until you reroll them, which is what makes trying a style cheap.
Appended last so it can never push character identity out of the prompt's strongest region.

Cast

Everyone this story can draw. Identity lock is copied into every prompt the character appears in, so it is what keeps a face the same across a chapter. Extras are crowd art: they never reach the storyboard as people.

Character bible

appearance is the identity lock, injected into every prompt this character appears in. Write it once; editing it mid-story desyncs new panels from old ones.

Panel

Written in plain language and applied by the script model. It only touches what the panel looks like: never who is in it, never the dialogue.
Only ticked characters get their identity lock in the prompt. An untucked one drifts into whoever the model feels like drawing.
